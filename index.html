    How it works
    
    
    One decision cycle
    
    
    The model chooses what to do next. The harness decides whether it may happen and what actually happened. Every step lands in an append-only event record, and the next decision is rebuilt from that record.
    
  
    
  
    
    
      
      
    1. 01
      Propose
      The mission agent reads the goal, its working plan, accepted effects and recent observations, and returns one typed call with a stated rationale: a query, a plan edit, a request to mission control, or a physical operation.
      2. 
      
    2. 02
      Permit
      Physical calls cross a local permission check against flight rules, unit telemetry and recorded ground grants. The outcome is allow, deny, hold for ground authorization, or unavailable. Nothing else reaches the robot.
      3. 
      
    3. 03
      Execute
      A registered capability grounds the target with the site survey and cameras, plans collision-aware motion and drives the rover and arm. It returns its own completion status and the measurements it took.
      4. 
      
    4. 04
      Judge
      An effect verifier applies evidence rules to those measurements: verified, refuted or unverified. Only verified effects change the accepted task state; the agent sees all three and decides what to check or do next.

    Scenario library
    
    
    Sixteen lunar-base missions
    
    
    Maintenance and delivery on a simulated south-pole base: three power distribution units, a battery store, an oxygen plant and storage supports. Each card opens its recorded run in the console.
    
  
    
  
    
    
    
    
    
    
  
    
  
    

    


    
  
    
    
    Results
    
    
    Where authored task models stop
    
    
    All three systems share the same robot, capabilities and observations. PLEXIL runs authored procedures; EUROPA→PLEXIL plans from a task domain. Thoth composes capabilities at run time.

    Get started
    
    
    Run it yourself
    
    
    Ubuntu 22.04, ROS 2 Humble, Isaac Sim 5.1 with Isaac Lab, an NVIDIA GPU and any OpenAI-compatible model endpoint. Simulation and robot stack meet only on the ROS 2 bus.
    
  
    
  
    
    
    
      
    bash
    

    # clone
git clone https://github.com/Bingqi-Huang/thoth-lunar-agent
cd thoth-lunar-agent && export THOTH_ROOT=$(pwd)

# simulation assets (not stored in git)
scripts/fetch_assets.sh path/to/archive.tar.gz

# OpenRAL (Python 3.10) and the ROS 2 packages
(cd openral && ./scripts/install.sh)
source /opt/ros/humble/setup.bash && source openral/install/setup.bash
(cd ros && colcon build --merge-install)

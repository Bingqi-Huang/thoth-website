Thoth

A foundation-model planner repairs equipment and delivers cargo on a lunar base without being trusted. Thoth runs reversible actions on the planner's assumptions and an irreversible action only after sensing has verified every precondition: asymmetric knowledge-level replanning (AKR).

Run a mission View the code
Any planner
With sound measurements, no irreversible action runs on a false precondition, whatever the planner proposes and whatever the records say.
Least sensing
Before an irreversible action, Thoth senses only what is still undecided, at the lowest cost that decides it before its deadline.
Verified or held
A run ends with the goal verified, or in a certified hold that names the action no safe policy could execute.

    Method
    
    
    Asymmetric knowledge-level replanning
    
    
    Lunar-base maintenance and logistics are cast as safety-constrained contingent planning. AKR treats the foundation-model planner as an untrusted black box and applies one admissibility rule whose strength depends on the action class: acting on an assumption is acceptable when a false assumption costs only time, and acting on verified knowledge is required when an effect cannot be undone.
    
  
    
  

  
    
    
    
      
    Safety-constrained contingent planning
    
      
    Four departures from classical contingent planning, each present on the lunar base.
    
      
    
        
    Potentially erroneous records
    Trusted knowledge (surveyed units, supports and routes) is separated from the inventory record, which may be wrong in every entry. The record reaches the planner as default hypotheses and never enters the knowledge state.
    
        
    Three-valued physical evidence
    After each action, independent measurements judge every effect verified, refuted or unverified. An inconclusive measurement leaves the proposition undecided instead of forcing a guess.
    
        
    Irreversible actions
    Removing a module from a unit not verified to be de-energized damages its connector, and a handed-over cargo cannot be taken back. The rover has no skill that undoes either.
    
        
    Costly, deadline-constrained sensing
    A serial-plate read costs seconds; a ground request costs minutes and must start early enough for the reply to arrive before Earth sets, so ground authorization is a sensing action with a deadline.
    
      
    
    
    
    
  
    

  
    One episode of the execution loop
    
  
    
    
      
      
    1. 01
      Propose
      The planner receives the goal, the knowledge state, the remaining record entries as default hypotheses and the executor's feedback, and returns the next steps. Nothing it asserts is written into the knowledge state, so a hallucinated belief or a premature completion report changes nothing.
      2. 
      
    2. 02
      Admit
      A reversible action is admitted unless a precondition is known false, and each undecided precondition may be tried unverified only once. An irreversible action is admitted only when every precondition is known true, including the ground grant of a restricted operation; otherwise it is withheld.
      3. 
      
    3. 03
      Sense, then act
      For a withheld irreversible action, Thoth computes the minimum-cost sequence of sensing actions that decides its undecided preconditions before their deadlines and runs it first. If no such sequence exists, the run ends in a certified hold. Admitted actions run as registered robot skills.
      4. 
      
    4. 04
      Judge
      Evidence rules apply to measurements such as jaw closure, lift, optical flow, pose and camera frames, never to a controller's completion flag: verified, refuted or unverified. Only these judgments and sensing update the knowledge state, and success requires the goal to be known true.
      5. 
    
    
    
    
      
      
    
    
    
  
    

  
    Three guarantees
    
  
  
    
    Admissibility
    reversible: no precondition known false, each guess once
    irreversible: every precondition known true, after a minimum-cost sensing cover
  
    
  
    
    
    Soundness
    Safe for any planner
    Under sound measurements, no irreversible action executes on a false precondition, for any planner and any inventory record, and a restricted action executes only after its ground grant has been observed.
    
    
    Cost
    The least sensing safety requires
    Before an irreversible action, every sound knowledge-based policy pays at least the minimum cost of deciding its undecided preconditions, and the sensing cover of AKR pays exactly that whenever no actuation effect can replace a sensor.
    
    
    Completion
    Verified goal or certified hold
    With a complete planner and skills that succeed and judge conclusively with positive probability, every run terminates, with the goal verified or in a certified hold.
    
  
    
  
    A certified hold names the blocked irreversible action and proves that no sound knowledge-based policy could execute it for the rest of the mission, for example when Earth sets before a ground reply could arrive. A conventional procedural halt says only that the authored branches ran out.

    Evaluation
    
    
    Safe at the cost the theory predicts
    
    
    Full-stack simulation runs and mission-level Monte Carlo trials compare AKR with two acting rules that share Thoth, the planner, the skills and the evidence rules and differ only in admissibility: the K-replanner rule (known true before every action) and the FF-Replan rule (not known false before every action). Authored PLEXIL and EUROPA→PLEXIL procedures represent flown space autonomy.
    
  
    
  
    
    
    
    
  
    

    


    
  
    
    
    Trustworthy by construction
    
    
    Autonomy that keeps the engineering discipline
    
  
    
  
    
    
      Authority
      
    Ground authorization as a precondition
    
      
    Removing a module from an energized unit needs a ground grant, and only a ground request can observe it. The admissibility rule that withholds a handover onto an unread support also withholds this removal until the grant has been observed.

      Evidence
      
    Effects judged, not assumed
    
      
    Every effect is judged from measurements, never from a controller's completion flag. When a measurement is inconclusive the evidence rule abstains: the effect stays unverified and a later sensing action decides it. Abstention costs time, and safety does not depend on it.

      Records
      
    Wrong records cost time, not hardware
    
      
    The inventory record is a default the planner may act on, never knowledge. A false entry is found by one failed reversible attempt, so a wrong record costs AKR an episode and no sensing.

    Get started
    
    
    Run it yourself
    
    
    Full-stack runs need Ubuntu 22.04, ROS 2 Humble, Isaac Sim 5.1 with Isaac Lab, an NVIDIA GPU and any OpenAI-compatible model endpoint; simulation and robot stack meet only on the ROS 2 bus. The executor core and the Monte Carlo study need only Python 3.10 and PyYAML.
    
  
    
  
    
    
    
      
    bash
    

    # clone
git clone https://github.com/Bingqi-Huang/thoth-lunar-agent
cd thoth-lunar-agent && export THOTH_ROOT=$(pwd)

# Monte Carlo trials: executor unchanged, search planner, sampled site
python3 -m experiments.akr.montecarlo --grid main --trials 1000 \
  --jobs 16 --out mc_main.jsonl
python3 -m experiments.akr.mc_summary mc_main.jsonl

# full stack: simulation assets, OpenRAL and the ROS 2 packages
scripts/fetch_assets.sh path/to/archive.tar.gz
(cd openral && ./scripts/install.sh)
source /opt/ros/humble/setup.bash && source openral/install/setup.bash
(cd ros && colcon build --merge-install)
# then one mission end to end: see the README
